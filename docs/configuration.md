# 配置与网络行为

[返回首页](../README.md)

日常设置优先在界面中修改。认证服务器输入框是草稿，点击“应用”才会生效；登录、登出或切换期间，相关编辑暂时禁用。

## 账号与运营商

用户名按学校要求填写。部分部署使用后缀区分线路，例如 `username@cmcc`、`username@unicom` 或 `username@chinanet`；学校未要求后缀时填写原始账号即可。

客户端优先按服务器返回的用户名唯一精确匹配本地账号。服务器只返回基础名时，只有能够唯一对应本地账号才会确认；重复账号或多个相同基础名会按歧义处理。

## 登录与恢复规则

- **单账号登录**：登录点选账号；接口成功后进入“等待确认”，由 `rad_user_info` 核实会话。
- **切换登录**：检测到其他本地账号在线时，先校验目标用户名及密码，再逐一登出全部配置账号，最后登录目标。单个登出失败会记录错误并继续；清理完成后重新解析目标绑定地址。
- **一键登录**：按配置顺序尝试，首个请求成功或确认在线后停止；已有在线或等待确认的会话时不主动切换。
- **登录失败恢复**：默认一轮最多尝试 3 次，间隔 1000 ms。实际请求最终失败后，逐一登出全部配置账号，再重新解析目标 IP、获取 challenge 并重试一轮；恢复再失败不会递归清理。该流程不限于 `err_code=2`。密码无法读取时提前退出；切换登录还要求目标用户名和密码非空。
- **手动登出**：暂停当前进程的自动重连，直到再次手动登录；内部恢复清理不触发这项暂停。

切换、登录及恢复共用同一个认证操作锁。切换后的确认优先查询新目标的网卡/IP，旧账号登出失败留下的在线标记不会抢走确认目标。

## 网卡与 TUN

登录时先解析绑定网卡的当前 IPv4；绑定不可用时尝试配置的备用 `ip`，再尝试检测到的校园网 IPv4。登出优先使用该账号原会话 IP，没有会话地址时才按登录规则解析。

启动时读取网卡地址并缓存在内存中。服务器持续确认在线时复用缓存；返回未登录、请求失败或会话账号/IP 变化时，先刷新地址。绑定 IP 改变后通过新地址重新确认，再决定是否重连。手动刷新重新读取地址，实际登录、重连前重新解析目标绑定；未绑定网卡的纯静态 IP 配置无需枚举网卡。没有可用 IPv4 时保留账号并等待地址恢复。

校园网地址自动检测会排除常见虚拟网卡，但自定义名称可能无法识别，因此建议明确绑定真实校园网网卡。

HTTP 代理禁用与源 IP 绑定都不会修改 Windows 路由，不能保证绕过 Clash / Mihomo TUN。`strict_bind` 默认关闭：网卡绑定默认用于选择 Srun 协议中的 IP，认证连接是否严格绑定源地址由该选项控制。状态查询使用源 IPv4 绑定；客户端不会关闭 Clash/TUN 或改写系统路由。

## 启动与状态检查

开机自启和自动重连默认开启。启动时先查询认证状态，只有明确未登录时才按账号顺序自动尝试；已在线、等待确认或状态未知时保留当前会话。

主页状态卡常驻显示“当前内网 IP”：优先使用当前有效在线会话的 `10.x.x.x`，否则显示缓存的校园网 IPv4；没有有效地址时显示“未检测到”。该显示复用现有状态，不额外扫描网卡或发起网络请求，也不表示账号已认证。

`rad_user_info` 是认证状态的权威来源。查询超时、未知响应或格式错误按查询失败处理，前两次失败不会直接判为掉线；连续失败至少三次后才允许使用启用中的降级探测。状态响应支持 UTF-8 / GBK 解码，无法可靠解码时显示错误，不直接判为离线。

IPv4 外网探测默认关闭。开启后用于辅助路由诊断和状态同步持续失败时的降级判断；外网可达不会把校园账号标为在线。服务器确认已在线时，外网探测失败只提示路由问题。未绑定请求可能经过 TUN、IPv6 或其他网卡，其结果不作为校园 IPv4 登录状态依据。

## 各账号的在线 IP

账号卡片在本机在线/离线状态下方显示“账号在线 IP”，来自自服务网站，包含该账号在其他设备上的登录地址。因此，本机离线的账号也可能有在线 IP；这份列表不改变本机认证状态。

“常用设置”中可单独开启或关闭自动查询，并将“在线 IP 查询间隔”设为 **1–1440 分钟，默认 5 分钟**。它与本机状态检查的秒级间隔分别运行：启动建立地址缓存后执行第一轮；以后按各账号上次尝试时间计时，失败也等待同一间隔，不立即循环重试。调整分钟间隔后按新间隔计算下一次查询。

每个账号使用独立的内存 Cookie 会话，优先复用网页登录；失效后最多重新登录自服务一次。它只读取在线列表，不调用校园网登录、登出、失败恢复或设备下线，也不重新枚举网卡。查询失败保留上次 IP 和更新时间，并标注“上次结果”；只有识别到明确的空列表才显示“暂无在线 IP”。未知网页、账号不符或无法完整读取的分页都显示查询失败。

默认仅为内置 `http://10.0.0.55` 网关使用已核实的 `http://10.0.0.54:8800` 自服务。更换学校或网关后，不会自动向该地址发送新账号凭据；其他采用兼容自服务流程的部署，需在配置中明确填写 `self_service_url`，例如 `https://self-service.example.edu`。只填写可信的服务根地址，不含路径、查询参数或账号密码；普通网页登录需要验证码的部署可能无法自动查询。

网页凭据、密码摘要和 Cookie 不写入日志或新增磁盘缓存。自服务使用 HTTP 时，单点登录参数仍需按凭据保护。接口调查与实测范围见[接口报告](../campus_net_auth_probe_report.md)；新增客户端功能使用合成响应离线验证，没有为验证而登出或改变真实会话。

## 配置项

配置文件为 `C:\ProgramData\CampusNetClient\config.json`，缺失字段使用默认值。以下列出常用字段；完整结构见 [AppConfig](../src/service/config.rs)。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `server` | `http://10.0.0.55` | 内置认证地址，需按本校部署修改 |
| `auto_start` | `true` | Windows 开机自启 |
| `auto_reconnect` | `true` | 自动登录及重连 |
| `minimize_to_tray` | `true` | 关闭、最小化时收起到托盘 |
| `monitor_interval_secs` | `30` | 状态检查间隔，单位为秒 |
| `enable_online_sessions` | `true` | 独立查询各账号在自服务中的在线 IP |
| `online_sessions_interval_mins` | `5` | 在线 IP 查询间隔，运行时限制为 1–1440 分钟 |
| `self_service_url` | 空字符串 | 显式自服务根地址；留空时仅默认网关使用已核实的北理工地址 |
| `enable_ipv4_internet_probe` | `false` | 可选 IPv4 外网探测 |
| `detect_ip` | `false` | 通过认证服务器辅助识别客户端 IP |
| `strict_bind` | `false` | 认证连接严格绑定源 IP |
| `double_stack` | `false` | Srun 双栈参数 |
| `n` | `200` | Srun 登录参数 |
| `utype` | `1` | 登录类型；读取旧配置时兼容 `type` |
| `acid` | `8` | Srun 区域或接入点参数，可能需要按学校调整 |
| `retry_times` | `3` | 每轮登录尝试次数 |
| `retry_delay` | `1000` | 重试间隔，单位为毫秒 |
| `language` | `zh` | 界面语言：`zh` 或 `en` |
| `users` | `[]` | 账号列表，每项包含用户名、密码字段及可选网卡/备用 IP |

## 配置备份与迁移

配置保存使用临时文件替换正式文件，并维护 `config.json.bak`。主配置损坏时，保留 `config.json.bad-<timestamp>` 副本并尝试恢复备份；主配置缺失时也优先使用备份。两者都不可用时使用默认配置，并在日志中提示。

旧版 exe 同目录的 `config.json` 可在启动时迁移到 ProgramData。界面修改在后台合并保存，正常退出和自动更新前会再保存最新配置。

密码字段仅使用 Base64 编码，可被还原；配置和备份都需要妥善保管。ProgramData 为机器级存储目录，目前没有 Windows 凭据保护或按用户隔离存储。
