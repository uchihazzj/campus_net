# Campus Net Client · 校园网客户端

基于 Srun / 深澜认证协议的 Windows 桌面客户端，支持多账号管理、切换登录、开机自启、自动重连和托盘运行。

[下载 Windows x64](https://github.com/uchihazzj/campus_net/releases/latest/download/campus-net-client.exe) · [版本与更新记录](https://github.com/uchihazzj/campus_net/releases) · [问题反馈](https://github.com/uchihazzj/campus_net/issues)

## 主要功能

- **账号管理**：添加、编辑和删除账号，支持单账号操作及一键登录、登出。
- **切换登录**：已有账号在线时，先登出全部配置账号，再登录点选账号。
- **状态确认**：以认证服务器返回的会话为依据，显示当前账号、IP、在线时长、流量及套餐信息。
- **自动连接**：支持开机自启；启动时先检查认证状态，确认未登录后自动尝试登录，掉线后按策略重连。
- **网卡绑定**：按网卡名称选择校园网接口，适应 DHCP 地址变化；正常在线时复用网卡缓存。
- **桌面常驻**：支持托盘、深浅主题、中英文界面，以及通过 GitHub Releases 检查和安装更新。

适用于使用 Srun / 深澜认证的校园网。不同学校的认证地址和参数可能不同，需要按本校要求设置。

## 安装与首次使用

1. 从 [最新 Release](https://github.com/uchihazzj/campus_net/releases/latest) 下载 `campus-net-client.exe`。
2. 放到用户可写的目录，例如 `%USERPROFILE%\CampusNet\`，双击启动。
3. 在“常用设置”中填写学校的认证服务器地址，点击“应用”。
4. 点击“添加用户”，填写账号和密码，优先绑定实际连接校园网的网卡。
5. 点击“登录”，等待界面显示“已确认在线”。

用户名及运营商后缀按学校要求填写，客户端不会自动补写。开机自启和自动重连默认开启，可在“常用设置”中调整。

## 日常操作

| 操作 | 行为 |
| --- | --- |
| 登录 | 登录指定账号，成功后等待服务器确认 |
| 切换登录 | 先逐一登出全部配置账号，再登录点选账号；切换期间可能短暂断网 |
| 一键登录 | 按账号顺序尝试，首个成功后停止；已有在线或等待确认的会话时保留当前会话 |
| 登出 / 一键登出 | 登出指定或当前活动账号，并暂停本进程的自动重连，直到再次手动登录 |
| 刷新状态 | 重新读取网卡/IP，并向认证服务器查询当前会话 |
| 关闭 / 最小化窗口 | 默认收起到托盘；通过托盘点击或右键“显示窗口”恢复，彻底退出请用托盘菜单 |

“等待确认”表示登录请求已成功、会话仍在核实；“状态未知”表示暂时无法判断。只有服务器确认有效会话后才显示“已确认在线”，外网能访问不等于校园账号已认证。

实际登录失败时，客户端会尝试逐一登出全部配置账号，再重试当前目标一轮。无法读取的密码等本地校验错误不会触发清理。详见[登录与恢复规则](docs/configuration.md#登录与恢复规则)。

## 网卡与代理

推荐绑定实际校园网网卡，避免手动固定 DHCP 分配的 IP。正常在线时复用地址缓存；出现离线迹象或会话变化时先刷新地址，再判断是否需要重连。

Clash / Mihomo TUN 可以保持开启，但源 IP 绑定不保证绕过 TUN 路由。客户端不会自动关闭代理或修改系统路由；IPv4 外网探测默认关闭。更多说明见[网卡与 TUN](docs/configuration.md#网卡与-tun)。

## 配置与日志

运行数据默认保存在 `C:\ProgramData\CampusNetClient\`：

| 文件 | 用途 |
| --- | --- |
| `config.json` | 账号及设置 |
| `config.json.bak` | 配置备份 |
| `app.log` | 运行日志 |

密码目前使用可还原的 Base64 编码，**不属于加密存储**。请妥善保管配置、备份及日志，反馈问题前先移除账号等个人信息。

## 更新与文档
